Logic Gates Simulator
This project is a simple graphical user interface (GUI) application that allows users to simulate basic logic gates (AND, OR, NOT, NAND, NOR, XOR) using Python's tkinter library.

Features
Simulate basic logic gates: AND, OR, NOT, NAND, NOR, XOR.
User-friendly GUI to input values and select logic gates.
Display results of the logic gate operations.
Requirements
Python 3.x
tkinter library (usually included with Python)
Usage
Run the logic_i_vis.py script.
A window will appear asking for the number of input gates (1 to 14).
Enter the input values for the gates.
Select the desired logic gate from the dropdown menu.
Click the "Calculate" button to see the results.
Logic Gate Functions
AND(a, b): Returns the AND operation of a and b.
OR(a, b): Returns the OR operation of a and b.
NOT(a): Returns the NOT operation of a.
NAND(a, b): Returns the NAND operation of a and b.
NOR(a, b): Returns the NOR operation of a and b.
XOR(a, b): Returns the XOR operation of a and b.
